# `official-doc-cn-system-fonts-12pt` preset

## 适用场景

明确要求采用小四号正文体系，且运行或交付环境仅提供通用 `黑体 / 楷体 / 仿宋` 字体名称的中文正式文档。

这是 `official-doc-cn-system-fonts` 的小四版变体。公文大标题使用小二号，一级、二级、三级标题和正文均使用小四号；只有在具体材料、单位模板或用户明确要求小四版时，才选用本 preset。

## 结构化样式表

- 页面大小：A4
- 页边距：上/下 `2.54 cm`，左/右 `3.18 cm`（继承工程基线值）
- 全文文字行距：固定值 `20 磅`
- 除公文标题段后留一行外，其余文字段前、段后：`0`

| Markdown / 样式 | 字体 | 字号 | 对齐 / 字形 | 缩进 / 编号 |
| --- | --- | --- | --- | --- |
| `#` / 公文标题 | `黑体` | 小二号（`18 pt`） | 居中；段后留一行 | 无 |
| `##` / 一级标题 | `黑体` | 小四号（`12 pt`） | 左对齐 | 首行缩进两字符（`24 pt`）；编号按 Markdown 原文输出 |
| `###` / 二级标题 | `楷体` | 小四号（`12 pt`） | 左对齐 | 首行缩进两字符（`24 pt`）；编号按 Markdown 原文输出 |
| `####` / 三级标题 | `仿宋` | 小四号（`12 pt`） | 左对齐、加粗 | 编号按 Markdown 原文输出 |
| 普通段落 / 正文 | `仿宋` | 小四号（`12 pt`） | 两端对齐；标点不溢出版心 | 首行缩进两字符（`24 pt`） |

JSON 定义中的 `paragraph_defaults` 统一控制全文文字的行距和段距，各个 `styles` 只声明字体、字号、字形、对齐和缩进等差异。图片所在段落为避免固定行距压缩图片，单独使用自适应单倍行距。

## 可选页面内容

- 页眉：继承 `official-doc-cn-system-fonts`，使用仿宋五号（`10.5 pt`），下方带 `0.5 pt` 黑色单线
- 页脚：继承 `official-doc-cn-system-fonts`，使用宋体五号（`10.5 pt`）
- 文本水印：继承 `official-doc-cn-system-fonts`，使用黑体 `36 pt`，默认颜色 `#D9D9D9`、透明度 `0.25`、旋转 `-45°`

页眉、页脚和水印默认不显示。需要时在 Markdown 开头使用 YAML frontmatter：

```yaml
---
header:
  left: 某某单位
  right: 内部材料
footer:
  center: "— {page} / {pages} —"
watermark:
  text: 内部资料
---
```

页眉支持 `left`、`right`；页脚支持 `left`、`center`、`right`。两者均可使用 `{page}`、`{pages}`、`{title}`、`{date}` 动态字段。中页眉不受支持。字体、字号和水印外观由 preset JSON 控制，不写入 frontmatter。

## 推荐 Markdown 写法

- `#`：公文标题
- 标题下方直接写主送机关或称谓段落
- `##`：一级标题；需要编号时写成 `## 一、XXXX`，不需要时直接写标题内容
- `###`：二级标题；需要编号时写成 `### （一）XXXX`，不需要时直接写标题内容
- `####`：三级标题；需要编号时写成 `#### 1. XXXX`，不需要时直接写标题内容
- 普通段落：正文内容，每段空一行
- `| ... |`：原生 Word 表格；表头加粗并跨页重复，列宽根据内容分配后允许 Word 自动调整
- `![说明](./image.png)`：插入本地图片，按嵌入式输出；图片所在段落改为单倍行距
- `<!-- pagebreak -->`：需要分页时显式插入

标题编号属于文档内容，由 Markdown 显式写入。导出器不会自动添加、删除或重排编号，因此同一级别可以同时使用有编号和无编号标题。

## 与 `official-doc-cn-12pt` 的区别

- 不使用 `方正小标宋简体`
- 不使用 `楷体_GB2312`
- 不使用 `仿宋_GB2312`
- 更适合系统内仅提供通用 `黑体 / 楷体 / 仿宋` 字体的环境

## 示例

```md
# 关于开展示例工作的通知

各有关单位：

为统一输出格式，现将有关事项通知如下。

## 一、工作目标

### （一）总体要求

#### 1. 任务分工

请各单位提高认识，认真落实。

## 结语

请结合实际抓好后续工作。
```

## 当前边界

当前只是“小四版、通用字体名称的公文样式变体”，还不是完整公文排版规范。发文字号、签发人、落款、成文日期、附件说明和抄送规则等仍需按具体文件要求处理。
